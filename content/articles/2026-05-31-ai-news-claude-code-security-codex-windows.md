# 2026年5月31日時点のAI最新情報まとめ

## Anthropic：Claude Codeにセキュリティプラグインと「ultracode」モードが追加

Anthropicは5月27日、Claude Code向けの無料セキュリティプラグイン「security-guidance」を一般公開した。このプラグインはコードを編集するたびにリアルタイムで脆弱性パターンを検出し、`eval()`・`os.system()`・`dangerouslySetInnerHTML`などを含む約25種類の危険なパターンを自動フラグする。内部テストでは、プルリクエストに対するセキュリティ指摘コメントが30〜40%削減されたと報告されており、公開から24時間で157,000ダウンロードを記録した。

あわせて、Claude Codeに新設定「ultracode」が追加された。努力レベル(effort)を `xhigh` に自動設定し、タスクに応じて動的ワークフローを自律的に組み立てる。コードベース全体のバグ調査・プロファイラー主導の最適化監査・セキュリティ監査などが並列処理で実行できるようになり、大規模リポジトリへの対応力が大幅に向上した。

## OpenAI：CodexがWindowsのPC操作に対応・モバイルから遠隔制御も可能に

OpenAIは5月29日、CodexのWindows向けComputer Use機能を正式公開した。Codexがユーザーの画面を見ながらクリック・入力を行い、Windows上のデスクトップアプリをエージェントとして操作できる。さらにiOS/AndroidのChatGPTモバイルアプリとWindows PCを連携させることで、移動中にスマートフォンからタスクを開始・確認・承認するリモート操作が実現した。

この機能により、テスト環境の立ち上げ・ビルド確認・コードレビューのステップをAIエージェントが自律的に回してくれる「ハンズフリー開発」が現実味を帯びてきた。GPT-5.5 Instantも同期間にレスポンスの読みやすさ・会話の自然さが改善されている。

## エンジニア転職への意味

Claude Codeのセキュリティプラグインとultracodeモードは、「コーディングができる」だけでなく「AIを使って安全なコードを素早く届けられる」エンジニアの市場価値を底上げするトレンドを加速させる。セキュリティ知識をAIツールと組み合わせて運用できるSESエンジニアは、単純にコードを書くだけの開発者との差別化要因を得る絶好のタイミングにいる。

OpenAIのCodex Windows対応も同様で、AIエージェントを「使う側の人間」として設計・監視・改善できるエンジニアへの需要は今後さらに高まる。転職市場では「AIツールを使いこなした実績」を具体的に語れるかどうかが、書類通過率と面接評価を左右するポイントになってきている。

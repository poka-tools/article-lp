# 2026年05月25日時点のAI最新情報まとめ

## OpenAI Codex：デスクトップAIエージェントへの進化

OpenAIは2026年5月24日、Codexをコード実行ツールから本格的な**デスクトップAIエージェント**へと変貌させたことを発表しました。

この数週間で行われた複数の大型アップデートにより、CodexはMacアプリケーションを独自のカーソルで操作し、スクリーンキャプチャによる記憶蓄積、スケジュール実行、さらにモバイル端末からのリモート監視まで対応するようになりました。

### 主なアップデート内容

**ロック中のPC操作（Locked Computer Use）**
Mac利用ユーザーが対象。Macをロックした状態でもCodexがリモートで安全に作業を継続できるようになりました。エンジニアがその場を離れた間もバックグラウンドで処理が走り続けます。

**ブラウザ操作の大幅強化**
高精度アノテーションモード、JavaScript読み取り専用コンテキスト、タブグルーピングなどが追加。ウェブスクレイピングや調査タスクの精度が向上しています。

**Slackやカレンダーとの連携**
ChatGPTユーザーはSlack・Google Drive・メール・カレンダーなど日常業務ツールと接続し、定型業務を自動化できるようになりました。コーディング以外のオフィスタスクにも活用範囲が広がっています。

**モバイルアプリからのリモート監視**
ChatGPTモバイルアプリからデスクトップで動くCodexセッションをリアルタイムに確認・承認操作できます。ターミナル出力・ファイル差分・スクリーンショットを外出先から確認できる設計です。

## Anthropic：Claude Code Routinesが正式提供開始

Anthropicは2026年5月、**Claude Code Routines**をPro・Max・Team・Enterpriseプランのウェブ版ユーザー向けに正式提供しました。

RoutinesはClaudeに定型のコーディングタスクを定期実行させる仕組みで、以下のプランごとに1日あたりの実行数が設定されています：

- **Proプラン**：1日最大5ルーティン
- **Maxプラン**：1日最大15ルーティン
- **Team・Enterpriseプラン**：1日最大25ルーティン

ルーティンにより、テスト実行・コードレビュー・ドキュメント生成などの反復作業をスケジュールで自動化できます。エンジニアは高度な判断を要する作業に集中できる環境が整いつつあります。

### Claude Managed Agentsの追加機能

あわせて、Claude Managed Agentsに以下の新機能が追加されました：

- **Dreaming（ドリーミング）**：エージェントセッションとメモリストアを定期レビューし、パターンを抽出してエージェントが自律的に改善される仕組み
- **マルチエージェントオーケストレーション**：複数のエージェントを連携させて複雑なタスクを分担実行
- **Outcomes・Webhooks**：タスク完了時の通知や外部システムへのコールバック設定

## エンジニア転職への意味

AIがコーディング以外の日常業務も担い始めたことで、エンジニアに求められるスキルセットが再定義されつつあります。単にコードを書けるだけでなく、**AIエージェントを設計・監視・改善できる能力**が転職市場で高く評価されるようになっています。

Claude Code RoutinesやCodexのデスクトップ操作機能を実務で使いこなした経験は、即戦力アピールに直結します。ツールの更新に合わせて自身の開発ワークフローを継続的に最適化する姿勢が、今後の差別化ポイントになるでしょう。

# CodexがChatGPTデスクトップに統合——「チャット・仕事・コーディング」が1画面に（2026年7月26日時点）

## OpenAI：Codexアプリを新ChatGPTデスクトップに統合

OpenAIは2026年7月9日から、独立していた **Codex アプリを新しい ChatGPT デスクトップアプリに統合** し始めました。Codex は消えるわけではなく、「Chat（対話）」「Work（仕事）」と並ぶ専用のコーディング体験として、同じデスクトップアプリ内に収まる形になります。

この新しい ChatGPT デスクトップアプリは Mac・Windows 向けにグローバル提供され、Chat・Work・Codex は無料プランを含むすべてのプランで使えます。これまで用途ごとにアプリを行き来していた作業が、一つのウィンドウで完結するようになったのが大きな変化です。

## 新機能：音声・複数フォルダ・移行インポート

統合と同時に、開発者にうれしいアップデートがいくつも入りました。

- **ChatGPT Voice（GPT-Live 搭載）**：音声で作業を相談しながら、Chat・Work・Codex のタスクを声で調整できます。手を止めずに指示を出す使い方が現実的になりました。
- **複数フォルダ対応**：デスクトップアプリのローカルプロジェクトで、関連する複数フォルダをまとめて扱えるようになりました。プロジェクトのメニューから主フォルダを選べます。モノレポや複数リポジトリをまたぐ作業に効きます。
- **スレッド履歴の強化**：ページ送り対応の履歴、効率的な再開、検索、名前の保持、サブエージェント対応、メモリなどが追加されました。
- **移行インポートの拡張**：`/import` が Cursor や Claude Code の設定・MCPサーバー・プラグイン・セッション・コマンド・プロジェクト単位のメモリまで取り込めるようになりました。他ツールからの乗り換えコストが下がっています。

## エンジニア転職への意味

今回の統合が示すのは、AIツールが「単機能の便利ツール」から「開発ワークフロー全体を抱える基盤」へと移りつつある流れです。対話・業務・コーディングが一つのアプリにまとまり、音声や複数フォルダ、他ツールからの移行までカバーする——これは、企業が「AIを前提にした開発環境」をチーム標準として整えていくことを意味します。

転職市場では、この変化を追い風にできる人が有利です。具体的には、「Cursor も Claude Code も Codex も一通り触って、自分のプロジェクトに合う形で使い分けられる」という適応力を、面接で成果と結びつけて語れること。ツール移行が `/import` 一発で済む時代だからこそ、差がつくのは「どのツールを設定できるか」ではなく「AIを組み込んで開発フローをどう速く・堅くしたか」という設計の話です。SES・受託でさまざまな現場環境に順応してきた経験は、この「ツールに縛られず環境を整える力」としてアピールできます。伝え方さえ知っていれば、経験年数以上に評価される余地があります。

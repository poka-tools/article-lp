# 2026年5月28日時点のAI最新情報まとめ

## Anthropic：Claude CodeがAuto Mode・使用量インサイト・自己ホストサンドボックスを追加

AnthropicはClaude Codeに複数の実務直結アップデートを展開しました。なかでも注目は**Claude Code Auto Mode**です。エージェントが自律的にコーディングタスクを進めながら、重要な判断ポイントでのみ人間の承認を求める「ヒューマン・アプルーバルゲート」方式を採用しています。従来の「すべてのコマンドを逐一承認」から「必要な場面だけ介入」に転換することで、長時間の自律コーディングセッションを安全に回せるようになりました。

使用量の可視化も強化されています。新しい `/usage` コマンドでは、スキル・サブエージェント・プラグイン・MCPサーバー別にリソース消費の内訳を確認できます。Claude Codeを本番ワークフローに組み込んでいるチームにとって、コスト管理とボトルネック特定が大幅に楽になります。

インフラ面では**自己ホストサンドボックス（Self-hosted Sandboxes）**がパブリックベータとして公開されました。センシティブなファイル・パッケージ・社内サービスを自社インフラ内に閉じたまま、Claude Managed Agentsを動かせます。プライベートMCPサーバーとの接続にも対応しており、エンタープライズのセキュリティ要件を満たしながらAIコーディングエージェントを導入できる環境が整いました。

UI面では差分ビュー（/diff）のキーボード操作対応、Markdownタスクリストのレンダリング改善、パーミッション・トランスクリプト・履歴まわりの多数のバグ修正が含まれています。

## OpenAI：GPT-5.5 InstantがChatGPTの新デフォルトモデルに、Codexモバイルプレビューも開始

OpenAIは**GPT-5.5 Instant**を全ChatGPTユーザーに順次展開し、これまでのデフォルトだったGPT-5.3 Instantを置き換えました。APIでは `chat-latest` として参照できます。

最大の改善点はハルシネーション（誤情報生成）の大幅な削減です。医療・法律・金融など高リスク領域のプロンプトにおいて、GPT-5.3 Instantと比較して**ハルシネーションを52.5%削減**したと社内評価で報告されています。また、回答の簡潔さ・会話トーンの自然さ・文脈理解の精度も向上しています。

新機能として**メモリソース（Memory Sources）**が全ChatGPTモデルに導入されました。回答のパーソナライズに使われたコンテキスト（保存済みメモリ・過去のチャット履歴・Gmail連携データ）を明示的に確認でき、古い情報や誤った記憶を削除・修正できます。プライバシーと透明性の観点から重要なアップデートで、Plus・Proユーザー向けにWeb版から順次展開されます。

さらに**Codexモバイルプレビュー**がChatGPTアプリで開始されました。MacでCodexエージェントを動かしながら、スマートフォンからスレッドの開始・継続・アクション承認・差分確認・テスト結果のレビューが可能になります。移動中でも開発フローを止めずに管理できる体制が整い、エンジニアのワークスタイルが変わりつつあります。

## エンジニア転職への意味

Claude Code Auto ModeとGPT-5.5 InstantのCodex統合は、「AIエージェントを運用管理する」スキルへの需要を確実に押し上げます。自己ホストサンドボックスやMCPサーバー構成の知識は、セキュリティ要件の厳しい金融・医療・エンタープライズ領域での採用条件として明示される可能性が高く、インフラとAIの両方を理解できるエンジニアの市場価値は一段高まっています。Codexモバイルの普及により「AIコーディングエージェントを使いこなした実務経験」は今後の転職要件として標準化が進む見込みで、早期に日常ワークフローへ組み込んだエンジニアほど面接での説得力が増すでしょう。

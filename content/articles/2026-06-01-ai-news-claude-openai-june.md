# 2026年6月1日時点のAI最新情報まとめ

## Anthropic：Claude Agent SDKの課金モデルを6月15日に分割・プログラマティック利用が別プールへ

Anthropicは5月14日、6月15日付で実施するサブスクリプション課金構造の大幅な改訂を発表した。これまで月額定額の上限に一括でカウントされていたプログラマティック利用（Agent SDK・`claude -p`コマンド・Claude Code GitHub Actions・サードパーティエージェント）が、通常チャット利用とは切り離され、専用の「Agent SDKクレジット」プールに移行する。

プランごとの追加クレジット枠はProが月20ドル・Max 5xが月100ドル・Max 20xが月200ドルで、APIのフル料金レートで消費される（翌月への繰り越しなし）。Claude.ai上でのインタラクティブチャット・ターミナルからのClaude Code・Claude Coworkは従来通りサブスクリプション枠のままで変更はない。Anthropicは6月8日にユーザーへクレジット付与案内メールを送付する予定で、ユーザー側での事前アクションは現時点では不要とされている。

この変更の背景には、月20〜200ドルのサブスクリプション料金を払いつつ、OpenClawなどのサードパーティツールで数百〜数千ドル相当のトークンを消費するヘビーユーザーへの対応がある。2月に禁止、4月に制限強化、5月に「分割課金」という形で正式に再開放された経緯をたどっており、エージェント活用の費用構造をユーザー側が把握・管理できる仕組みへの移行といえる。

## Anthropic：Claude Opus 4.8がGitHub Copilotで正式提供開始

AnthropicのフラッグシップモデルClaude Opus 4.8が、GitHub Copilotで一般提供（GA）に移行した。Opus 4.8はコードの理解・生成性能において前世代モデルから明確に向上しており、実際の開発タスクへの対応力が強化されている。またClaude Sonnet 4・Claude Opus 4モデルはAPIで6月15日に廃止予定となっており、利用中の開発者は最新モデルへの移行が求められる。

## OpenAI：GPT-4.5が6月27日に廃止・GPT-5系列への世代交代が加速

OpenAIは、ChatGPTにおけるGPT-4.5の提供を6月27日に終了すると発表した（30日間のサンセット期間を経ての廃止）。あわせてo3モデルも2026年8月26日に廃止予定（90日サンセット）となっており、GPT-4世代から GPT-5シリーズへの移行が一段と加速している。

現在ChatGPTのデフォルトモデルは5月5日にリリースされたGPT-5.5 Instantで、高リスクな質問（医療・法律・金融）でのハルシネーション発生率がGPT-5.3 Instant比52.5%削減されたと内部評価で報告されている。API側でのGPT-4.5廃止は今回の対象外だが、今後のロードマップでは段階的な移行が見込まれており、開発者・エンジニアはモデル切り替え計画を意識しておく必要がある。

## エンジニア転職への意味

今回の変更が示すのは、「AIを使う」から「AIのコスト構造を理解して運用できる」スキルが現場で必要とされ始めているという転換点だ。AnthropicのAgent SDK分割課金は、エージェント活用が単なる「試し使い」から業務組み込みに移行したことの証左であり、プログラマティック利用の設計・コスト管理ができるエンジニアへの需要は今後さらに高まる。OpenAIのモデル世代交代も同様で、GPT-4系からGPT-5系への移行対応を実務で経験したことは、転職時に「AIリテラシーの高さ」を示す具体的な実績として語れる。

SESエンジニアがこれらの経験を転職活動に活かすなら、「AIツールを導入した」という曖昧な表現よりも「Agent SDKの課金モデル変更に対応してコストを◯%削減した」「モデル移行時の動作検証を設計・実施した」といった定量・定性の両面で語れる内容に落とし込むことが、書類通過率と面接評価を高める鍵になる。

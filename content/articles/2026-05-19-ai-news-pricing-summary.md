## OpenAI: GPT-5.5とAPI料金

OpenAIのヘルプセンターでは、GPT-5.5 Instantがログインユーザー向けの標準体験として案内されています。Free、Plus/Go、Business/Proで利用上限やコンテキスト長が異なり、ThinkingやProの使い方もプランによって変わります。

API料金では、GPT-5.5、GPT-5.4、GPT-5.4 miniの単価が案内され、Batch APIの50%削減、Data residencyの10%上乗せ、Web searchやContainersの料金も示されています。

出典: [GPT-5.5 in ChatGPT](https://help.openai.com/en/articles/11909943-gpt-52-in-chatgpt%3Futm_source)、[OpenAI API Pricing](https://openai.com/api/pricing/)

## Claude: プランとAPIモデル価格

Claudeの料金ページでは、Free、Pro、Max、Team、Enterpriseに加え、Opus 4.7、Sonnet 4.6、Haiku 4.5などのAPI価格が案内されています。Claude CodeやProjects、Research、Workspace連携などを使う場合は、単なるチャット料金ではなく、業務フロー全体で見る必要があります。

出典: [Claude Pricing](https://claude.com/pricing)

## Gemini: 検索付きAIアプリのコスト

Gemini APIでは、Free、Paid、Enterpriseの違いに加えて、モデル別料金、Context caching、Batch API、Google SearchやMapsのツール料金が案内されています。検索グラウンディングを使うAIアプリでは、モデル単価だけでなく検索コストも見る必要があります。

出典: [Gemini Developer API pricing](https://ai.google.dev/gemini-api/docs/pricing)

## GitHub Copilot: モデル、レビュー、データレジデンシー

GitHub Copilotでは、BusinessとEnterpriseのベースモデルがGPT-5.3-Codexへ変更されています。また、2026年6月1日からCopilot code reviewがAI CreditsとGitHub Actions minutesの両方に関係する料金構造になる予定です。

さらに、US/EUのデータレジデンシーとFedRAMP対応では、モデル倍率が10%上乗せされることも案内されています。企業利用では、モデル性能だけでなく、地域、コンプライアンス、予算管理が重要です。

出典: [GPT-5.3-Codex in Copilot](https://github.blog/changelog/2026-05-17-gpt-5-3-codex-is-now-the-base-model-for-copilot-business-and-enterprise/)、[Copilot code review billing](https://github.blog/changelog/2026-04-27-github-copilot-code-review-will-start-consuming-github-actions-minutes-on-june-1-2026/)、[Copilot data residency](https://github.blog/changelog/2026-04-13-copilot-data-residency-in-us-eu-and-fedramp-compliance-now-available/)

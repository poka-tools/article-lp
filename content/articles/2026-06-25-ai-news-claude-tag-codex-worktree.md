# 2026年6月25日時点のAI最新情報まとめ

6月後半は「AIが個人の補助ツールからチームの一員へ」という流れがはっきり見えた2週間でした。Anthropic（Claude）とOpenAI（ChatGPT・Codex）の両陣営とも、単発の質問応答ではなく「チームの中で継続的にタスクをこなす存在」へと製品の重心を移しています。エンジニアの働き方、そして転職市場での評価軸にも直結する内容なので、要点を整理します。

## Anthropic（Claude）：Slackに常駐する「Claude Tag」とスケジュール実行エージェント

6月23日、AnthropicはSlackのチャンネル内で `@Claude` をメンションしてタスクを委任できる **Claude Tag on Slack**（ベータ）を投入しました。チャンネルの会話文脈を蓄積し、ツール・データ・コードベースに接続したうえで、非同期でタスクを進行できるのが特徴です。Enterprise / Team 向けで、裏側のモデルは Opus 4.8 が使われています。

さらに6月17〜18日にかけて、**Claude Managed Agents のスケジュール実行（cronによる定期起動）** が公開ベータに入り、夜間のデータ同期・週次のコンプライアンススキャン・日次ダイジェストといった定常業務を、人間が起動しなくても回せるようになりました。あわせて **Claude Code に Artifacts 機能** が追加され、生成したWebページを共有・ライブ更新できるようになっています。認証面では静的APIキーを短命の権限スコープ付き資格情報に置き換える **Workload Identity Federation（WIF）** が一般提供化されました。

これは「Claudeに質問する」から「Claudeにタスクを預けて回す」への明確な転換点です。

## OpenAI（ChatGPT・Codex）：Codexがブランチ・worktreeを扱い、ChatGPTは対話を整理

OpenAI側は開発者ワークフローの作り込みが進みました。6月のCodex更新では、新規スレッドで **ブランチの選択・git worktreeの作成・環境セットアップスクリプトの実行** ができるようになり、複数の作業を並行して走らせる前提の設計に寄せています。モバイルのCodexにはプロフィール画面（使用量・トークン消費の可視化）や `/goal` によるゴール管理、6月22日には「ホストごとの応答スタイル（Friendly / Pragmatic）設定」や「フォークした会話から元スレッドへのリンク」も追加されました。6月15日のiOS版では、ワークスペースのファイルブラウザや差分の一括展開・折りたたみも入っています。

ChatGPT本体では、GPT-5.2系がGPT-5.5系へ統合（既存会話は自動的にGPT-5.5へ継続）され、回答を **棒・折れ線・円・散布図のインタラクティブなグラフに変換** する機能や、5往復を超える長い会話への目次表示が追加されました。一方でCanvasはGPT-5.5系では廃止され、執筆・コーディングはチャット内のブロックで完結する形に変わっています。

## エンジニア転職への意味

両社が同じ方向に進んでいる点に注目してください。AIは「コードを書いてくれる相棒」から「ブランチを切り分け、定期実行され、チームのチャンネルに常駐してタスクを引き受ける同僚」へと変わりつつあります。つまり、現場で評価されるエンジニア像も「自分でコードを全部書ける人」から「AIエージェントに仕事を設計して任せ、複数の作業を並行で回し、出力をレビューして責任を持てる人」へとシフトしています。これは経験年数の長さだけで勝負しづらくなる一方で、SESや受託で多様な現場・タスクをさばいてきた人にとっては追い風です。要件を分解してタスク化し、ツール連携を組み、品質をチェックする——その段取り力こそが、まさに今求められている力だからです。

転職市場では「AIを使えます」では弱く、「AIエージェントにこの定常業務を任せて工数を◯割削った」「worktreeで並行作業を回してリリース速度を上げた」といった具体的な運用実績が差になります。日々の業務でこうした新機能に触れておくことが、面接で語れる材料に直結します。今の現場での経験は、伝え方さえ知っていれば、思っているより市場で高く評価されます。

# OpenAI API料金を開発チームが見るときのポイント

## 公式URL

[OpenAI API Pricing](https://openai.com/api/pricing/)

## 何が分かるか

OpenAIのAPI料金ページでは、GPT-5.5、GPT-5.4、GPT-5.4 miniなどのモデル別料金が案内されています。2026年5月19日時点では、GPT-5.5は入力が100万トークンあたり5ドル、キャッシュ入力が0.5ドル、出力が30ドルです。GPT-5.4は入力2.5ドル、出力15ドル、GPT-5.4 miniは入力0.75ドル、出力4.5ドルです。

また、Batch APIでは入力と出力を50%削減でき、Data residencyは標準料金に10%上乗せされる形で示されています。Web searchは1,000コールあたり10ドル、コンテナは容量とセッション単位の課金が案内されています。

## 料金表で見るべき点

API料金を見るときは、入力単価だけで判断しない方がよいです。AIアプリでは、プロンプト、検索結果、ファイル、ツール実行ログ、思考用の中間情報などが入力に含まれます。さらに、ユーザーに返す回答が長い場合は出力単価が効いてきます。

高性能モデルをすべての処理に使うと、コストはすぐに膨らみます。日常的な分類、要約、テンプレート生成はmini系、設計判断や複雑な推論は上位モデル、夜間の大量処理はBatch APIというように分けるのが現実的です。

## 開発現場での設計

コスト設計では、まずリクエストの種類を分けます。ユーザーの入力に即時応答する処理、裏側でまとめて処理できる処理、検索やファイルを伴う処理、コード実行を伴う処理です。

次に、失敗時の再試行や長文コンテキストの扱いを決めます。毎回すべての情報を入れるのではなく、キャッシュ、要約、差分入力を使うことでコストを抑えられます。Web searchやコンテナのようなツール料金も、モデル料金とは別に監視する必要があります。

## エンジニア転職への影響

AIアプリ開発経験を転職で語るなら、「APIを使った」だけでは弱いです。モデル選定、Batch API、キャッシュ、検索、コンテナ、データレジデンシーなど、コストと要件のバランスをどう取ったかを説明できると強くなります。

職務経歴書では、「OpenAI APIを利用」ではなく、「処理種別に応じてモデルを分け、Batch APIとキャッシュを使ってコストを抑えた」のように書くと、実務の設計力が伝わります。
